# Falsification matrix

Active or explicitly negative gate rows are linked to demonstrated controls through
these stable registry IDs: source response (`GATE-SOURCE-KMS-RESPONSE`), equal-energy
entropy confound (`GATE-ENTROPY-CONFOUND`), modular localization
(`GATE-MODULAR-LOCALIZATION`), blind topology (`GATE-BLIND-TOPOLOGY`), non-geometric
controls (`GATE-NONGEOMETRIC-CONTROLS`), and parameter robustness
(`GATE-PARAMETER-ROBUSTNESS`). Rows that are not implemented do not yet have an
acceptance gate and therefore cannot have a passing mutation control.

Negative results must remain in version control with the same prominence as passes.
Changing the source law, inference rule, or acceptance threshold requires a recorded
decision and a rerun of all relevant controls.
