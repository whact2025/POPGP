# POPGP claims matrix

Status vocabulary: **implemented** means the named computation exists;
**benchmark-supported** means selected finite tests pass; **negative result** means a
required behavior failed; **placeholder** means code exists but is not the proposed
physical object; **conjecture** and **unimplemented** carry no numerical confirmation.

| ID | Claim and source | Status / implementation | Evidence and limitation | Falsification or upgrade requirement | Recommended wording |
|---|---|---|---|---|---|
| C01 | Pre-geometric substrate (`docs/framework.md` §§4.1–4.3) | Conjecture; `ExactBackend` starts from a qubit Hamiltonian on a chain/grid interaction graph. | No coordinates enter inference, but adjacency is encoded in the Hamiltonian. | Recover robust relational observables across inequivalent microscopic representations without importing target topology. | “Coordinate-free finite quantum substrate with an encoded interaction graph.” |
| C02 | Atemporality / phase order (framework §4.3) | Conjecture; code uses ordinary unitary evolution parameter `dt`. | Re-labeling time as phase order does not establish atemporality. | Construct an operational observable distinguishing phase order from assumed external time. | “Unitary phase-flow parameter used as a model coordinate.” |
| C03 | Stability-selected factorization (framework §4.4.2a) | Benchmark-supported surrogate in `popgp/coarse_grain.py`. | Exhaustive partition search selects contiguous blocks for the 8-qubit chain across five probe seeds; no causal gradient flow is implemented. | Show convergence with probe count, system size, perturbations, and an implemented local flow whose attractor agrees with search. | “Finite exhaustive stability-selection benchmark.” |
| C04 | Finite distinguishability / capacity (`popgp/capacity.py`) | Implemented functional, unvalidated physical postulate. | Cut capacity and a relative-entropy inequality checker exist. | C05 | Area-law emergence | Conjecture. | C09 | Local metric reconstruction (`PiGeomResult.h_ab`) | Implemented embedding-space prototype. | Regularized SPD fits report residual, rank, and condition number. | C10 | Clock potential (`_solve_clock_constraint`) | Implemented numerical constraint. | Correct zero-mode handling, residual reporting, negative-well sign, slower clocks, and redshift convention are tested. | Demonstrate stability across graph refinement and consistency with an independently measured clock observable. | “Finite graph clock-constraint diagnostic.” |
| C11 | Araki/KMS physical source (framework §4.4.5) | Negative results for raw relative entropy and the symmetric-chain reduced-state modular source; feasible microscopic KMS-energy candidate. | Under affine mixing, every fixed-observable expectation and the linear graph solve are exactly ε-linear, so those slopes are identity regressions. For the non-affine KMS family `ρ(ε)∝exp[-β(H+εV)]` with localized `V`, direct order/floor/negative-control gates give `D=O(ε²)` and a signed Richardson estimate gives nonzero first-order modular susceptibility matching Kubo--Mori across the declared β≤3 sweep, including 2.5. Physical energy follows by identity. Isospectral controls gate only `ΔS=0` and `D=Δ⟨K⟩` at roundoff scale; slopes are descriptive. The `−βΔ⟨h_i⟩` source sums to minus global modular-energy change only after its supplied reference passes the runtime Gibbs-state check for the same backend Hamiltonian and β. The graph and energy split are supplied conventions. | Establish state-independent localization, temporal averaging, covariant conservation, scalable refinement/continuum behavior, and an independent clock observable. | “Raw relative entropy and naive reduced modular localization fail; a microscopic KMS-energy density is a family-dependent finite-chain test object.” |
| C12 | Newtonian limit | Not demonstrated. | A manually injected source solves a chosen screened graph equation on 3×3 nodes; two shells cannot establish a continuum law. | Refinement with fixed physical scale, boundary analysis, 1/r or log-law discrimination, Poisson normalization, and source matching. | “Green-function and sign unit test, not Newtonian validation.” |
| C13 | Einstein/Regge closure | Unimplemented; a 2D embedding-Delaunay angle-deficit proxy is integrated. | The proxy lacks intrinsic edge reconstruction, dual volumes, refinement, Einstein tensor, source tensor, and closure residual. | Convergent intrinsic Regge implementation plus closure and discrete Bianchi/conservation tests. | “Angle-deficit plumbing prototype; closure remains proposed.” |
| C14 | Lorentz symmetry | Conjecture. SU(2) tests cover spatial rotations only. | No boosts, dispersion relation, or limiting-speed measurement. | Quantify anisotropy and boost violations with experimental-scale bounds. | “SU(2)-equivariant toy coarse graining; Lorentz recovery open.” |
| C15 | Singularity regularization | Conjecture. | Bounded cell capacity or failed metric fit does not establish causal completeness. | Continued deterministic evolution through a controlled high-curvature model and discrete causal-trajectory extendibility. | “No singularity-resolution result.” |
| C16 | Born rule | Theoretical proposal, not tested by this repository. | Standard density-matrix probabilities are assumed. | Derive operational probabilities without assuming the rule and compare alternatives. | “Out of current simulation scope.” |
| C17 | Standard Model program | Conjectural roadmap. | No gauge group, chiral matter, spectrum, or couplings. | Reproduce anomaly-free field content and quantitative observables. | “Speculative future direction.” |
| C18 | Junction accessibility | Conjecture. | No operational junction detector or transition simulation. | Define measurable access criterion and reproduce it in controlled dynamics. | “Undefined in current code.” |
| C19 | Physical-AI interpretation | Interpretive conjecture. | CA example is an analogy and does not test quantum gravity or cognition. | Pre-register distinct predictions and controls. | “Exploratory analogy, separate from physical validation.” |

The strongest current contributions are the reproducible exact information
primitives, common-probe stability search, blind finite-benchmark topology recovery,
honest clock-constraint solver, and tests that preserve a source-law negative result.
