# 3×3 correlation-topology benchmark

This example tests whether a blind rule can reconstruct the interaction adjacency
encoded in a finite Heisenberg thermal state and whether its graph-geodesic distances
admit a low-stress two-dimensional embedding.

It is coordinate-free during inference, not topology-free: the state is generated by
a Hamiltonian whose interactions form a 3×3 grid. Ground-truth edges are held out
until after inference and are then used for precision/recall metrics.

## Run

```text
uv run python -m examples.physics_qg.grid_2d
```

The exact backend diagonalizes a 512×512 Hamiltonian, evaluates exact reduced density
matrices and mutual information, infers connectivity, computes graph geodesics, and
runs classical MDS.

Published configuration:

| Parameter | Value | Role |
|---|---:|---|
| Grid | 3×3 | Finite benchmark family |
| β | 2.0 | Thermal correlation scale |
| Cell size | 1 qubit | One inferred node per substrate qubit |
| `I_0` | 1.0 | Correlation-to-distance scale; larger than observed MI |
| Connectivity | adaptive MI gap + MST | Blind edge rule |
| Minimum gap ratio | 1.5 | Identifiability diagnostic |
| `lambda_dim` | 0.01 | Small dimension tie-breaker |

## Current result

- Positive MI range: approximately 0.0218–0.2688.
- Largest MI gap ratio: approximately 2.048, marked separable.
- Inferred edges versus held-out Hamiltonian edges: precision 1.0, recall 1.0.
- Selected embedding dimension: D*=2.
- MDS stress: approximately 0.168.
- Finite-graph heat-kernel dimension peak: approximately 1.50.
- Regularized local metric fits are reported with rank, condition, and residual.
- A 2D Delaunay/angle-deficit result is labeled as an embedding proxy.

The configured singleton resolution has retention loss approximately 3.44 against a
0.1 bound, so `Pi_res` is inadmissible and the committed validation artifact has
`overall_pass: false`. The downstream topology and geometry numbers remain useful as
conditional diagnostics; they are not a passing end-to-end projection result.

The heat-kernel value is a scale-dependent finite-size peak, not a continuum spectral
dimension. The topology result is a selected benchmark, not yet a robustness result
for larger grids, other temperatures, long-range Hamiltonians, or non-geometric
controls. Pairwise MI is used because the proposed QCMI filter is not implemented.

![Blind MI-graph embedding](results/embedding.png)

The plotted lines are inferred edges. Reference edges influence only the validation
metrics. The numbered coordinates are MDS visualization coordinates, not an input.

The clock-potential panel is generated by the standard pipeline’s local von Neumann
entropy placeholder. Its nearly uniform result is not a physical gravity test.
